# 🚀 Estudos em Sistemas Embarcados – CH32V003 (RISC-V)

Bem-vindo(a) ao repositório!

Este espaço é dedicado ao estudo, desenvolvimento e experimentação com **Sistemas Embarcados**, tendo como foco principal o microcontrolador **CH32V003**, baseado na arquitetura **RISC-V**.

O objetivo deste repositório é reunir exemplos práticos, testes, experimentos e projetos desenvolvidos durante o processo de aprendizado e exploração dos recursos desse microcontrolador.

A ideia é documentar descobertas, testar funcionalidades e compartilhar códigos que possam servir como referência para outros estudantes, desenvolvedores e entusiastas da eletrônica e dos sistemas embarcados.

## 🎯 Objetivos do repositório

- Estudar a arquitetura RISC-V aplicada a sistemas embarcados.
- Explorar os recursos e periféricos do microcontrolador CH32V003.
- Desenvolver exemplos práticos de programação.
- Realizar testes e experimentos com hardware.
- Compartilhar códigos e aprendizados.
- Criar uma biblioteca pessoal de exemplos que possa auxiliar em projetos futuros.

## 🔧 Hardware principal

**Microcontrolador:** CH32V003

**Arquitetura:** RISC-V (núcleo QingKe V2A)

**Fabricante:** WCH (Nanjing Qinheng Microelectronics)

O CH32V003 é um microcontrolador de baixo custo que oferece uma excelente oportunidade para estudar arquitetura RISC-V, programação de baixo nível e desenvolvimento de aplicações embarcadas.

## 📚 Conteúdo

Este repositório poderá conter exemplos e experimentos envolvendo:

- [ ] GPIO – Entradas e saídas digitais.
- [ ] Blink – Controle de LEDs.
- [ ] Timers – Temporizadores e contadores.
- [ ] PWM – Modulação por largura de pulso.
- [ ] ADC – Conversão analógico-digital.
- [ ] UART – Comunicação serial.
- [ ] SPI – Comunicação serial síncrona.
- [ ] I2C – Comunicação entre dispositivos.
- [ ] Interrupções.
- [ ] Watchdog Timer.
- [ ] Sleep Modes e gerenciamento de energia.
- [ ] Comunicação com sensores e periféricos.
- [ ] Testes de desempenho e experimentos diversos.

Os exemplos serão adicionados gradualmente, conforme os estudos e experimentações forem realizados.
